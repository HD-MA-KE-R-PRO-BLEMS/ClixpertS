# Clixpert S

**Clixpert S** — мощный и гибкий инструмент для автоматизации повторяющихся действий на экране. Поддерживает запись кликов мыши и нажатий клавиш, сложные условия (по цвету пикселя, области или поиску изображения), два режима работы (бесконечный или с ограничением по счётчику), прогресс-бар с расчётом оставшегося времени, сохранение профилей и сворачивание в системный трей.

## 📋 Возможности

- **Запись действий**  
  Клики мыши (с координатами) и нажатия клавиш записываются по горячим клавишам (настраиваются).  
  Поддерживается удержание кнопки мыши и паузы произвольной длительности.

- **Режимы работы**  
  - Бесконечный цикл.  
  - Ограниченный цикл с заданным начальным значением, вычетом за действие и множителем вычета.  
  Индивидуальный вклад в прогресс для каждого действия.

- **Условия выполнения**  
  Действие может выполняться только при выполнении одного из условий:
  - **Пиксель** — проверка цвета в конкретной точке экрана.  
  - **Цвет в области** — поиск заданного цвета в прямоугольной области.  
  - **Поиск изображения** — поиск фрагмента на экране (OpenCV).  

  Для каждого условия можно настроить допуск по цвету, а также поведение:
  - Ожидание выполнения условия (блокирует очередь до совпадения).  
  - Пропуск остальных действий в цикле при выполнении/невыполнении.

- **Прогресс и ETA**  
  Встроенный прогресс-бар и отдельное окно прогресса (опционально).  
  Автоматический расчёт оставшегося времени на основе текущего счётчика и вклада действий.

- **Гибкая настройка**  
  Глобальная задержка между действиями, настраиваемые горячие клавиши, допуск цвета, переключение языка (русский/английский).

- **Профили**  
  Сохранение и загрузка всей конфигурации (действия, условия, изображения в Base64) в JSON.

- **Системный трей**  
  Возможность свернуть окно в трей, горячие клавиши продолжают работать.

- **Современный интерфейс**  
  Тёмная тема в стиле «жидкого стекла» (полупрозрачные матовые панели).

## 🛠️ Требования

- Windows (поддержка глобальных горячих клавиш через `keyboard`)
- Python 3.7+
- Библиотеки: `pyautogui`, `keyboard`, `pystray`, `pillow`, `opencv-python`, `numpy`

Установка зависимостей:
```bash
pip install pyautogui keyboard pystray pillow opencv-python numpy
```

## 🚀 Запуск

```bash
python clixpertS.py
```

Для работы глобальных горячих клавиш может потребоваться запуск от имени администратора.

## 📦 Сборка в EXE

```bash
pyinstaller --onefile --windowed --icon=clixpertS.ico --name="Clixpert S" clixpertS.py
```
